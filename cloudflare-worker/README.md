# سرور واسط Cloudflare Worker برای خرید هوشمند (Smart Buy)

این ورکر برای حل محدودیت‌های امنیتی مرورگر (CORS) هنگام فراخوانی مستقیم سامانه‌های ایرانی در محیط Production طراحی شده است:
- **سازمان غذا و دارو (سرفود)**: `cerfood.ir`
- **مرکز ملی شماره‌گذاری کالا (ایران‌کد)**: `irancode.ir`
- **سامانه پروانه نشان استاندارد و کپچا**: `isom.inso.gov.ir`

## نحوه راه‌اندازی (فقط ۱ بار)

در ترمینال همین پوشه:
```bash
cd cloudflare-worker
npx wrangler deploy
```

پس از انتشار، یک آدرس به شکل زیر به شما داده می‌شود:
`https://smart-buy-proxy.<your-subdomain>.workers.dev`

می‌توانید آن آدرس را در بخش تنظیمات اپلیکیشن ذخیره نمایید، یا در پنل کلودفلر مسیر زیر را اضافه کنید تا مستقیماً روی دامنه‌تان کار کند:
- **Route:** `buy.mhkarami97.ir/api/*`
- **Zone:** `mhkarami97.ir`
